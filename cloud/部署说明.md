# 日报搬到云端（电脑关机也能自动推送）

当前日报跑在你自己的电脑上，电脑关机就断链。搬到 GitHub Actions 之后，
脚本在云端的服务器上定时跑，你只负责在手机上收日报。

## 已经准备好的

- `cloud/push_cloud.py` —— 云端推送脚本，不依赖本机钉钉登录态
- `.github/workflows/daily_report.yml` —— 定时工作流，工作日 22:00 / 周末 22:10
- `render_report.py` —— 已改成跨平台找字体（云端装 Noto CJK，本地仍用微软雅黑）

## 还需要你准备的 3 样东西

### 1. 一个 GitHub 账号（用来放代码和跑定时任务）
没有的话到 github.com 注册一个，免费的。

### 2. 一个可以推送代码的令牌
GitHub → 右上角头像 → Settings → Developer settings →
Personal access tokens → Tokens (classic) → Generate new token，
勾选 `repo` 和 `workflow`，生成后把那串 `ghp_xxxx` 发给我。

### 3. 群里加一个自定义机器人
在「惠州一店管理组群」里：群设置 → 智能群助手 → 添加机器人 → 自定义 →
安全设置选「加签」，会给你两串字符：
- Webhook 地址里 `access_token=` 后面那串
- 加签用的 SEC 开头的密钥

把这两串发给我。

### 4. 艾特用的手机号（已收到，已写入配置）
余志玲、罗惠玲（第 2 张图）；马锦荃、谢海昇（第 3 张图）—— 已填进 `config.json` 的 `mentions_phones`。

### 5. 仓库要设成公开（图床的前提）
钉钉机器人发不了本地图片文件，只能发公网图片链接。免费图床用 GitHub 仓库 + jsDelivr CDN，
而 jsDelivr 只服务**公开**仓库。所以摩打账号密码已经从代码里剥离，改由仓库 Secrets 加密保存
（本地真实密码放在不上传的 `config_local.json`）。**公开的只有日报图片本身。**

## 上线后的变化

| 项目 | 现在 | 云端之后 |
|---|---|---|
| 电脑关机 | 当天没有日报 | 照常推送 |
| 断网 / 掉登录 | 会中断 | 不受影响 |
| 推送时间 | 工作日 22:00、周末 22:10 | 完全一样 |
| 艾特人 | 真 @，蓝色可点 | 有提醒，但不变蓝（自定义机器人的限制） |
| 图片 | 钉钉原生预览 | 走 CDN 链接，群里直接显示 |

## 两个已知的差别，先说清楚

1. **艾特效果弱一点**：自定义机器人的 markdown @ 能弹提醒，但不会变蓝、不能点击。
   想要跟现在一模一样的真 @，得让公司 IT 在钉钉开放平台开一个「企业内部应用」，
   拿到 AppKey / AppSecret 才行。可以先用机器人跑起来，IT 那边慢慢申请。

2. **图片走 CDN**：自定义机器人不能直接上传本地图片，图片会先传到仓库，
   再用 jsDelivr 的公网地址发出。国内访问偶尔会慢，如果哪天图刷不出来，
   可以换成腾讯云 COS（几块钱一个月，国内速度稳定）。
