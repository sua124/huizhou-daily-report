## 第 1、2 样：钉钉群机器人（手机钉钉 App）

1. 打开**钉钉** → 进入群 **「惠州一店管理组群」**
2. 点右上角 **「…」**（群设置）
3. 找到 **「智能群助手」**（有的版本叫「群机器人」/「机器人」）
4. 点 **「添加机器人」** → 选 **「自定义」**（通过 Webhook 接入自定义服务）→ 添加
5. 机器人名字填：**日报机器人**；头像随便选
6. **安全设置** 这里有两种选法，**推荐第 1 种**：
   - **方式 A（推荐）：选「加签」** → 页面上会同时显示
     - **Webhook 地址**：`https://oapi.dingtalk.com/robot/send?access_token=xxxxxxxxxx`
     - **加签密钥**：`SECxxxxxxxxxx`
     - **两个都复制保存**（这就是第 1、2 样）
   - **方式 B：选「自定义关键词」**，关键词填 **`日报`**
     - 这样只需要复制 Webhook 地址，**第 2 样可跳过**
     - （代码已支持，消息标题里固定带「日报」二字）
7. 点完成

> ⚠️ 只有**群主或群管理员**能添加机器人。如果你看不到「添加机器人」，需要找群主帮忙加，或者让他把你设为管理员。

## 第 3 样：GitHub 个人访问令牌（PAT）

GitHub 是免费的，用来代替你那台会关机的电脑跑代码。

### 3.1 注册账号（已有账号就跳过）
1. 手机浏览器打开 **https://github.com**
   - 页面太挤的话，浏览器菜单里勾 **「桌面版网站」**，操作会顺很多
2. Sign up → 用邮箱注册 → 邮箱里点验证链接

### 3.2 创建令牌
1. 登录 github.com → 点**右上角头像** → **Settings**
2. 左侧最下面 → **Developer settings**
3. **Personal access tokens** → **Tokens (classic)**
4. 右上角 **Generate new token** → 选 **Generate new token (classic)**
5. 按下面填：
   - **Note**：`daily-report`
   - **Expiration**：选 **No expiration**（永不过期，避免以后失效）
   - **Select scopes**：勾选 **`repo`**（会自动勾上它下面所有子项）和 **`workflow`**
6. 拉到底点 **Generate token**
7. **立刻复制那个 `ghp_` 开头的字符串** —— 关掉页面就再也看不到了，只能重新生成

## 需要你知道的两件事

### 1. 仓库必须是公开的（这是免费图床的代价）
钉钉机器人发不了本地图片文件，只能发**公网图片网址**，所以图片得先放到公网上。免费方案是 GitHub 仓库 + jsDelivr CDN，而 jsDelivr 只服务**公开仓库**。

我已经做了处理，公开也不会泄露密码：
- 摩打账号密码**已从代码里移除**，改由仓库的 Secrets 加密保存，公开页面上看不到
- 本地那份真实密码放在 `config_local.json`，已设为不上传

**唯一公开的是日报图片本身**（含营业额等经营数据）。URL 形如
`https://cdn.jsdelivr.net/gh/账号名/仓库名@提交号/reports/report_2026-11-01_01_经营概览.png`
外人要精确猜到"账号名+仓库名+提交号+文件名"才可能看到，实际被扫到的概率很低。

如果你觉得这不能接受，可选加固方案：**买一个对象存储**（腾讯云 COS / 阿里云 OSS，新用户有免费额度，之后一年大概几块钱），图片传那里，仓库就能改回私有。需要的话跟我说，我来改。

### 2. 凭证到手前，你电脑上照常跑
本地两个计划任务（工作日 22:00 / 周末 22:10）现在仍然生效，今晚 22:00 会照常发 11-02 的日报。等云端验证通过我再停掉，中间不会断档。
